# AutoSec-Patch 3-Minute Hackathon Demo Script & Video Storyboard

**Project Name:** AutoSec-Patch  
**Track:** Coding and Agent Engineering Track  
**Platform:** Nebius Token Factory & NVIDIA Nemotron Models  

---

## ⏱️ Video Structure (Total: 2 min 50 sec)

### 🎬 Scene 1: The Problem (0:00 - 0:30)
* **Visual**: Show traditional SAST / GitHub security alerts piling up (hundreds of unresolved CVEs).
* **Voiceover**: *"Modern CI/CD pipelines detect vulnerabilities in seconds, but human triage and manual patching take weeks. Developers face alert fatigue, and broken patches often introduce severe regression bugs."*

### 🎬 Scene 2: The Solution - AutoSec-Patch (0:30 - 1:00)
* **Visual**: Display the AutoSec-Patch CLI running against a multi-CVE SARIF report. Show the Hierarchical Model Mesh animated diagram.
* **Voiceover**: *"Introducing AutoSec-Patch: an autonomous Adversarial Co-Evolution SecOps Swarm powered by Nebius Token Factory and NVIDIA Nemotron models. Instead of single-prompt guessing, AutoSec orchestrates offensive Red Team agents against defensive Blue Team patch synthesizers."*

### 🎬 Scene 3: Live Swarm Execution & Nebius Token Factory (1:00 - 1:55)
* **Visual**: 
  1. Terminal view: `autosec remediate --sarif examples/enterprise_bench/sarif_multi_cve.json`.
  2. Point out **Nemotron-Nano** doing sub-second AST blast-radius scoping.
  3. Point out **Nemotron-3-Ultra** generating dynamic Red Team exploit PoCs.
  4. Point out **Nemotron-70B** synthesizing zero-side-effect unified diffs.
  5. Dual-verifier confirming immunity and passing 100% of test suites.
* **Voiceover**: *"Here, Nebius Token Factory serves our hierarchical model mesh. Nemotron-Nano handles AST scoping instantly. Nemotron-3-Ultra acts as our adversarial Red Team, synthesizing dynamic exploit PoCs, while Nemotron-70B crafts invariant-preserving patches. Our dual verifier ensures zero regressions and 100% exploit neutralization."*

### 🎬 Scene 4: Interactive Cockpit Dashboard & Token Savings (1:55 - 2:30)
* **Visual**: Open `dashboard.html` in browser. Show interactive dark-mode charts, side-by-side diffs, AST call-graph tags, and the ~68% token cost savings metric.
* **Voiceover**: *"AutoSec generates an enterprise-ready SecOps Cockpit. Security leads can inspect blast-radius node graphs, side-by-side diffs, and execution timelines. By tiering calls across Nemotron Nano, Super, and Ultra, AutoSec reduces token inference costs by over 68% compared to monolithic LLM routing."*

### 🎬 Scene 5: Conclusion & Open Source (2:30 - 2:50)
* **Visual**: GitHub repository page showing Apache-2.0 License, clean documentation, and CI/CD GitHub Action.
* **Voiceover**: *"Fully open-source under Apache 2.0 and production-ready for GitHub Actions. AutoSec-Patch: autonomous, verified, and cost-effective cyber defense powered by Nebius and NVIDIA. Thank you!"*
